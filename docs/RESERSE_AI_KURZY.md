# Rešerše kurzů umělé inteligence (stav k září 2026)

Přehled dostupných kurzů AI — česky i anglicky, zdarma i placené, rozdělené podle úrovní.
Ceny jsou orientační k **září 2026** a u komerčních platforem se mění (akce, předplatné, dotace); před nákupem si je ověřte na odkazu.

## Legenda úrovní

| Značka | Úroveň | Pro koho |
|---|---|---|
| **Ú1** | Úplný začátečník | Netechnik, žák SŠ, učitel nezávisle na aprobaci. Bez programování a matematiky. |
| **Ú2** | Pokročilý uživatel | Umí prompty, chce AI nasadit do práce/výuky, automatizace, generování obsahu. |
| **Ú3** | Vývojář | Programuje, chce stavět aplikace nad LLM API, agenty, RAG. |
| **Ú4** | ML/AI inženýr | Trénink a fine-tuning modelů, deep learning, matematické základy. |

## 5. Doporučené trasy

**Učitel / škola (SŠ), rozpočet 0 Kč**
1. Elements of AI česky (~30 h, certifikát) → 2. AI kurikulum od AI dětem (hotové metodiky do hodin) → 3. Workshop NPI ČR (akreditovaný DVPP, zdarma) → 4. Microsoft Learn Educator Center pro nástroje.

**Student SŠ / netechnik**
Elements of AI → Google AI Essentials nebo Generative AI for Beginners → Kaggle Learn (Intro to ML).

**Programátor, který chce stavět s LLM**
Anthropic Academy (Claude API, agenti) → Hugging Face LLM + Agents + MCP course → DeepLearning.AI short courses → volitelně AI-102 nebo AWS AI Practitioner jako doklad.

**Cesta k ML inženýrství**
Machine Learning Specialization (Coursera) → fast.ai nebo MIT 6.S191 → Karpathy Zero to Hero → certifikace Google Cloud PMLE.

## 6. Poznámky k metodice a spolehlivosti

- Zdroje: oficiální stránky poskytovatelů + srovnávací přehledy (viz odkazy v tabulkách). Ceny českých komerčních platforem (Seduo, Skillmea, robot_dreams, Czechitas, ENGETO) se mění po akcích a u části kurzů se prodávají v předplatném — proto jsou u nich uvedeny odkazy místo konkrétních částek tam, kde se cenu nepodařilo ověřit z primárního zdroje.
- „Zdarma" u mezinárodních platforem občas znamená *obsah zdarma, certifikát placený* (typicky edX, Coursera audit). V tabulkách je to vždy rozlišeno.
- Anthropic Academy, Hugging Face, Kaggle, Elements of AI a IBM SkillsBuild vydávají certifikát/odznak bez poplatku.
